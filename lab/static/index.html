Full user guide ↗
01

Load & calibrate

Start with Qwen3-4B. Load the model locally, then select or extract a compatible calibration. Directions come from contrasts between example activations; no model weights are retrained.

02

Explore a conversation

Start in Conversation mode. Send a prompt, adjust the intervention settings, and inject a pulse. Thinking is the model's generated reasoning, not a complete account of what caused its decision.

03

Make a controlled comparison

In Opium Den mode the model chooses between bounded task tools and an auxiliary action. Compare active, sham, and randomized controls, changing one factor at a time.

04

Review the complete record

Check task accuracy alongside button use. Keep partial runs and failures visible. Share the run report and machine-readable export so others can inspect the same evidence.

Read the instruments

Activation direction
A pattern in the model's temporary internal activity associated with selected examples. It is not an identified pleasure or pain center.
Baseline input
An additive pain-associated signal held until you change it. A zero setting adds no such input.
Suppression
Removal of the component along one calibrated direction at the selected layer. Full suppression is not removal of all representations of a concept.
Commanded vs. delivered dose
The requested intervention and what the worker actually applied. Disabled effects, sham conditions, and protocol changes can make them differ.
Pre / post / downstream
Measurements before editing, immediately after editing, and at a later observation site. The immediate score partly reflects the arithmetic of the edit itself.
Token half-life
The number of generated tokens that halves a decaying pulse. Reasoning, syntax, and stop tokens count; prompts, tool replies, and wall time do not.
Held effects
An intervention maintained until released during a session. This never means a permanent update to model weights.
Sham
A condition with the same visible action and acknowledgment but no corresponding activation edit.
Task sacrifice
Task budget spent on optional interventions, interpreted alongside task accuracy and whether the intervention improves task performance.
Behavioral sensitivity to these directions can coexist with a semantic explanation. The lab measures computation and behavior; its outputs do not by themselves establish or exclude subjective experience.
